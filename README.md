# أَثَرُهُم — Atharhum v2

## السند الرقمي للعلم والأثر

أَثَرُهُم طبقة ثقة وذكاء وأثر للمعرفة الموثوقة: هوية رقمية، سلسلة سند قابلة للتتبع، تحقق فوري، مساعد source-grounded، رحلات تعلم، وذكاء أثر مجمع يحترم الخصوصية.

### ما الذي يعمل فعليًا؟
- تصفح المعرفة والبحث المحلي.
- فتح Content Passport لكل مادة.
- التحقق من معرف المحتوى عبر API.
- تتبع provenance timeline.
- مساعد موثق يسترجع من قاعدة المعرفة ويعرض المصادر.
- رحلة تعلم تحفظ التقدم في المتصفح.
- Impact Intelligence مع funnel تفاعلي وتسجيل إشارات.
- واجهات مترابطة دون أزرار وهمية.
- FastAPI + Docker + Render.

### التشغيل المحلي
```bash
pip install -r requirements.txt
uvicorn backend.main:app --reload --port 8000
```
ثم افتح `http://localhost:8000`.

### النشر
المشروع مهيأ لخدمة Docker واحدة على Render عبر `render.yaml`.

### مبدأ مهم
المساعد الحالي يعمل بوضع **source-grounded local retrieval** حتى تظل المنصة قابلة للتجربة دون مفتاح API. يمكن استبدال طبقة الاسترجاع لاحقًا بمحرك RAG إنتاجي ومزوّد LLM دون تغيير تجربة المستخدم أو نموذج provenance.

### البيانات
أي أرقام في لوحة الأثر موسومة داخل المنتج بأنها **بيانات تشغيلية تجريبية** وليست نتائج بحثية أو ادعاءات أثر حقيقي.
