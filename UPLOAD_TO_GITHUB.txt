أَثَرُهُم v2 — طريقة الرفع

1) فك ضغط الملف على جهازك.
2) افتح مجلد atharhum_v2.
3) ارفع محتويات المجلد إلى مستودع GitHub الجديد/المستبدل.
4) في Render اختر Web Service من المستودع.
5) Runtime: Docker (سيقرأ Dockerfile تلقائيًا).
6) Health Check Path: /api/health.
7) لا تحتاج Node أو npm أو React.
8) بعد النشر افتح رابط الخدمة ثم اختبر:
   - المعرفة
   - جواز المحتوى
   - التحقق
   - المساعد الموثق
   - رحلة التعلم
   - ذكاء الأثر

لا تحذف النسخة الحالية حتى تتأكد أن النسخة الجديدة تعمل على Render.
